Préférences

Les paramètres effectivement retenus pour ce site. Page d'information, en lecture seule : rien ne se règle ici.

Langues

ParamètreValeur
Langue de référenceFrançais — les runs sont rédigés dans la langue de la demande, le français par défaut.
Langues disponiblesFrançais et anglais. La langue se déduit de l'URL : le français à la racine, l'anglais sous /en/. Le sélecteur est dans le pied de page.
Vue par défautAnglais sur l'accueil et sur le marché « personnalisation e-commerce » ; français partout ailleurs. Réglage provisoire (6 septembre 2026) : le français reste atteignable par le lien FR du pied de page, et ce choix est ensuite mémorisé.
Pages traduitesL'accueil, la documentation et ses quatre focus, les pages corporate, le marché « apps de perte de poids » (6 runs sur 7) et le marché « personnalisation e-commerce » (page + run S1). Une page non traduite renvoie vers sa version française plutôt que vers une page vide.

Accès et visibilité

ParamètreValeur
AccèsSite entièrement privé depuis le 18 septembre 2026 : chaque page, chaque jeu de données et chaque fichier de style passe par le contrôle d'accès commun à tous les projets. Aucune page publique. Les droits se règlent ailleurs, dans l'espace des comptes.
Indexationnoindex, nofollow, noarchive sur toutes les réponses, redirections comprises. Le site n'apparaît dans aucun moteur de recherche.
Mesure d'audienceCloudflare Web Analytics, sans cookie et sans identifiant personnel. La mesure est désactivée en local, pour que les previews de travail ne faussent pas les statistiques.
Cookies déposésUn seul, fonctionnel : la préférence de langue, quand le lecteur clique « FR » ou « EN ». Aucun cookie publicitaire ni de suivi.

Contenu suivi

ParamètreValeur
Marchés suivisQuatre : applications d'assistance à la perte de poids · cartes de vœux & d'expression sociale (États-Unis) · capital d'amorçage à micro-tickets · outils SaaS de personnalisation e-commerce.
Runs publiésTreize, répartis ainsi : 7 · 1 · 1 · 4. Deux marchés ont parcouru les quatre étapes du pipeline ; deux n'ont que l'étape 1.
RythmeAucun calendrier automatique : chaque run est déclenché à la demande. Un run n'est jamais modifié après publication.
Période de référenceChoisie run par run (6 mois, 1 an ou 3 ans) selon la vitesse du marché, et justifiée dans le rapport.

Conventions d'écriture

ParamètreValeur
Valeurs estiméesPréfixe « ~ » sur toute estimation ; « — » quand la donnée est introuvable. Une estimation n'est jamais présentée comme un chiffre établi.
UnitésEn toutes lettres — « milliard(s) $ », « million(s) $ » — jamais d'abréviation, pour écarter toute confusion de lecture.
GlosesUn terme défini est entre guillemets « … » en français, en italique en anglais. Les acronymes sont explicités à leur première occurrence.
Largeur de lectureColonne fluide qui suit la largeur de l'écran, identique sur toutes les pages de run (choix du 6 septembre 2026).
TypographiesHanken Grotesk (texte), IBM Plex Mono (étiquettes et chiffres), Instrument Serif (questions des frameworks).

Données

ParamètreValeur
Données structuréesConservées : chaque run embarque son canevas de données, versionné à côté de son rapport. Pas de base de données.
Données brutesNon conservées : les pages et articles consultés sont jetés après le run. La traçabilité passe par les sources, référencées et datées en annexe.
Données personnellesAucune n'est collectée par le site.
HébergementOVH (France). Site entièrement statique : aucun traitement côté serveur en dehors du contrôle d'accès.
